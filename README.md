## 📖 Overview

This repository documents hands-on implementations of core deep learning architectures, optimization techniques, and practical applications. The primary focus is on building neural network models from scratch as well as leveraging modern deep learning frameworks for computer vision, sequential data, and generative modeling.

---

## 🛠 Topics Covered
Foundations: Artificial Neural Networks (ANN), Backpropagation, Loss Functions, Gradient Descent Variants (SGD, Adam, RMSprop).

Computer Vision: Convolutional Neural Networks (CNNs), Feature Extraction, Object Detection, Image Classification.

Sequence Processing: Recurrent Neural Networks (RNNs), LSTMs, Attention Mechanisms.

Advanced Architectures: Transformers, Autoencoders, Generative Adversarial Networks (GANs).

Optimization & Regularization: Dropout, Batch Normalization, Weight Initialization, Hyperparameter Tuning.

## 💻 Tech Stack & Tools
Language: Python 3.8+

Frameworks: PyTorch / TensorFlow / Keras

Data Processing & Visualization: NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn

Environment: Jupyter Notebooks, Google Colab
